## 🚀 Features

### Web App (index.html)
- 💖 Beautiful romantic UI with animations
- 🌹 Floating hearts background
- ⏰ Countdown timer to Valentine's Day
- 📅 Interactive Valentine Week calendar
- 💌 Write & save love letters
- 🎉 Special popups for each day
- 📱 Mobile responsive design

### Desktop Notifier (Python)
- 🔔 System notifications
- 🖥️ Beautiful GUI popups
- 📅 Valentine Week calendar view
- 💝 Personalized messages

## 🎯 How to Use

### Web App
1. Open `index.html` in your browser
2. Enter your loved one's name
3. Explore the Valentine Week calendar
4. Write a love letter
5. Share the link with your valentine!

### Python Desktop Notifier
```bash
# Install dependencies
pip install -r requirements.txt

# Run the notifier
python valentine_notifier.py
```

## 💡 Tips

- Run the Python notifier on each day of Valentine Week for special surprises!
- Bookmark the web app and visit daily for unique messages
- Share the web app link with your loved one
